B · 报错速查

这一页按「看到什么 → 为什么 → 改成什么」组织。 先定位层，再改代码；不要看到一个异常就去改提示词。

怎么用

  1. 先看 HTTP 状态码，确定是鉴权、参数、冲突还是服务未就绪
  2. 再看异常类名，确定是模型、工具、权限还是协议
  3. 最后看「改成什么」，按最小改动验证
排查顺序

配置（key / URL / 模型名）→ 权限（401 / 403）→ 参数（400 / 422）→ 资源状态（404 / 409）→ 上游（429 / 5xx）→ 代码异常。

HTTP 状态码

状态 常见原因 改成什么
401 没带 X-User-ID，或自定义鉴权没通过；模型 key 错也可能在 provider 侧报 401 补身份头 / token；检查凭证与 base_url
403 能认证但资源访问策略未授权（共享凭证 / 知识库 / 渠道归属）；工具被拒绝是 ToolResultBlock(state=denied)，不是 HTTP 403 检查 resource_access_policy 与资源归属
404 资源 / 卡片 / 会话不存在；Hub 的 get_* 对隐藏条目也返回 404 确认 id 属于当前用户；不要靠猜 id
409 同一会话已有在途 run；重复安装 / 重名资源 等待或订阅事件；换名字 / 先停旧 run
422 请求体 schema 不合法：缺字段、类型错、枚举值不在范围 按 OpenAPI / JSON Schema 修请求体
429 provider 限流或配额耗尽；网关限流 退避重试、提高配额、切 fallback
503 /health：某个组件 not_ready；挂载子应用未跑 lifespan 检查 Redis / 存储 / 工作区初始化
5xx 未捕获异常、上游 5xx、数据库 / Redis 故障 看服务日志与 span 的 ERROR 状态

401 的默认来源是 get_current_user_id deps.py:35； 409 来自 POST /chat 捕获 RuntimeError _chat.py:154； 503 来自 /health 的组件检查 _health.py:83。

启动与安装

现象 原因 改成什么
ModuleNotFoundError: agentscope 没装或装到了别的 Python 确认 pip -V 与运行解释器一致；重装 2.0.11
ImportError: A2AAgent requires the A2A extra 没装可选依赖 pip install "agentscope[a2a]"
ImportError: qdrant-client 知识库向量库缺依赖 pip install "agentscope[vdb-qdrant]"
PortAudio / sounddevice 报错 本地声卡库缺系统依赖 Linux 装 libportaudio2；或改用浏览器传输
Address already in use 端口被占 换端口或停掉旧进程
启动即 503 Redis / 存储不可达；组件初始化失败 看 lifespan 日志；先修连接再启动

模型与重试

异常 / 现象 原因 改成什么
APITimeoutError 单次 HTTP 超时 client_kwargs={"timeout": 30}；检查网络
RateLimitError / 429 配额或 QPS 超限 只保留一层重试；退避 + 网关限流
请求次数远超预期 AgentScope、Agent、SDK 三层重试叠加 把另外两层 max_retries 设为 0
一直走 fallback 主模型 key / 模型名 / 区域错 先修主模型；fallback 只做兜底
空响应 / RuntimeError: Model returned an empty streaming response 流在中途断开，没有收到 is_last=True 检查 provider 流式稳定性；重试或降级
模型不认工具 schema 工具描述含糊、参数类型缺失 补 docstring、类型与 input_schema
AttributeError: ... formatter（测试里） 假模型没设 formatter 加 self.formatter = OpenAIChatFormatter()

工具与权限

现象 原因 改成什么
工具一直不执行，停在确认 权限为 ASK，没送回确认结果 处理 RequireUserConfirmEvent，发送 UserConfirmResultEvent
工具参数校验失败 模型传了 schema 之外的字段 / 类型 收紧 input_schema，在描述里举例
同一个工具反复失败 模型没看到错误原因 返回结构化错误；tool_retries_limit 会注入提示
工具超时但任务还在跑 被 ToolOffloadMiddleware 转后台，不是取消 查后台任务；不要重复触发同一调用
MCP 工具列表为空 只安装了，没装配到工作区；或连接失败 在工作区装配；看 MCP 健康状态
技能解压失败 压缩包根目录或唯一的顶层文件夹里没有 SKILL.md 重打目录结构；注意大小限制

服务与流式

现象 原因 改成什么
POST /chat 返回 409 同一会话已有 run 订阅 /sessions/{id}/stream；必要时 interrupt
SSE 没有输出 没订阅、连接被代理缓冲、事件未发布 关闭代理缓冲；先订阅再触发；看回放日志
后接入的客户端缺历史 回放日志被裁剪 / 过期 调整日志保留；前端主动拉消息接口
下载随机 401 / 403 多副本各自生成 download_secret 所有副本共享同一 secret
定时任务重复执行 多个副本都开了 scheduler 只保留一个进程 enable_scheduler=True
IM 消息重复 / 顶号 多个副本都建了长连接 只保留一个 enable_channel_worker=True
滚动发布丢在途请求 直接 SIGKILL 或 grace 太短 preStop + 足够 terminationGracePeriodSeconds

语音与 A2A

异常 / 现象 原因 改成什么
ValueError: audio must not be empty ASR 传了空字节 检查录音与文件读取；传 filename
ValueError: filename must not be empty 显式传了 filename=""；默认值是 audio.wav 不要清空 filename；内存音频已有默认扩展名
语音自己打断自己 外放，麦克风录到扬声器 戴耳机；或换带 AEC 的传输
NotImplementedError（send("文字")） 模型 supports_text_input=False 换模型或隐藏文字输入
WebRTC Offer 返回 409 未配置 realtime_model_config、turn_detection="none"，或会话正被文字运行占用 先配置模型 / 停掉文字运行；已有语音连接会被新 Offer 替换，不报 409
RuntimeError: A2A task ... is still running 远端 Task 还在跑，重发会重复执行 等待 / 查询 / 取消，不要立即重试
ValueError: A2AAgent supports text, raw, and URL parts 远端返回结构化数据 Part 让对方转成文本；或自定义解析
TaskNotFoundError 远端已忘记该 Task 适配器会自动降级为新 Task，无需手工处理

最后手段

  • 打开 debug 日志与 span，先定位层，不要盲改
  • 用第 22 章的假模型把问题缩到最小可复现
  • 对比 /health 组件状态与启动日志
  • 把失败样本脱敏后加入回归集，避免同类问题再发
