类型 用途
Msg(name, content, role)通用消息；content 是块列表

TextBlock / ThinkingBlock / HintBlock文本 / 思考 / 提示
ToolCallBlock / ToolResultBlock工具调用与结果；含 state

Msg.get_text_content() 拼接所有文本块； Msg.append_event(event) 从事件流组装消息。
