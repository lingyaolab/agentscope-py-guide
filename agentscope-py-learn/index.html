把 AgentScope Python 2.0.11 学到「能自己接进项目」

这不是官方文档的搬运，而是一套按工程落地顺序重排、每个结论都能回源码验证的教程。默认模型是 DeepSeek：便宜、国内直连、兼容 OpenAI 协议，适合把例子真正跑起来。示例全部是 Python 3.11+，每一章都有能复制运行的代码、一次请求的完整链路、以及「你会撞到什么错」。

我该从哪儿开始

  1. 先花 12 分钟读「学习地图」
    它会告诉你三条主线怎么用、章节为什么是这个顺序、以及没有 API Key 能学到哪一步。
    → 00 学习地图
  2. 装好环境（约 25 分钟）
    Python 3.11+ + 一个虚拟环境 + 一个依赖：agentscope==2.0.11。服务、RAG、沙箱按需再加 extra。
  3. 跑通第一次对话（约 35 分钟）
    → 01 环境与依赖：从 DeepSeekCredential 到 Agent.reply()，再看懂一次 ReAct 的循环边界。
如果你只想最快验证「这套东西能不能跑」

直接看 01 章的最小可跑：两个文件、一条安装命令、三行环境变量， 补一个 DEEPSEEK_API_KEY 就能看到输出。

三条学习主线

① 跟做线：照抄能跑

  • 每章「最小可跑」都是完整文件，含依赖与配置
  • 代码里出现的每个 API 都能在附录 C 的速查表里查到出处
  • 目标是「先跑起来」，不追求先看懂

② 理解线：知道它在干什么

  • 每章「端到端」把一次调用拆成组装输入、模型调用、工具执行、循环终止四段
  • 关键机制给分层图：谁持有状态、谁发事件、失败在哪一层

③ 避坑线：出错时知道看哪儿

  • 每章「陷阱与窍门」按「你会看到 X → 因为 Y → 改成 Z」写
  • 重点标出 1.x 到 2.0 的破坏性变更，网上大部分博客仍然停留在旧写法

事实来源与版本承诺

本站内容严格对应 AgentScope Python 2.0.11（tag v2.0.11）， 写作时逐条回源核对，来源只有三类：

类型 路径 用来确认什么
Python 源码 src/agentscope/agent/、model/、tool/、middleware/ 方法签名、默认值、抛错点、判定分支
包元数据 pyproject.toml Python 版本要求、依赖分组、extra 名称
官方文档源 docs/ 与 docs.agentscope.io 设计意图、能力边界、术语原文

页面上所有 文件名:行号 形的胶囊都是出处标签：单击复制完整路径，Ctrl/Cmd + 点击在 GitHub 上打开对应文件。

已知边界
  • AgentScope 2.0 是一次大规模架构重构：Message、Tool、Workspace、Permission、 Middleware 与 Service 等核心层全部重写。不要把 1.x 的示例直接搬过来。
  • 官方中文站已经覆盖模块参考；本站不重复翻译，只补「学习顺序、可运行工程、版本差异与踩坑」。
  • 进度与主题只保存在本机浏览器 localStorage，不会上传任何数据；首页进度卡可导出/导入 JSON。
