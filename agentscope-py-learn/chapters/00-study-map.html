00 · 学习地图

这一章不写代码，只解决三个问题：官方文档已经很全，为什么还要看这里、这个站该怎么读、 你现在缺的是哪块前置知识。读完再决定从第几章开始。

为什么要再造一个文档站

官方文档（docs.agentscope.io） 质量很好，而且有完整中文版。但它是一份 reference：按模块分篇，假设你知道自己要找什么。 初学者打开它，最常见的状态是「每一页都看得懂，但不知道先看哪一页」。

官方文档的立场 初学者遇到的后果 本站怎么处理
按模块组织：agent / model / tool / workspace 各一篇 看完 agent 篇还不知道它们怎么组合成一个能上线的服务 按落地顺序重排：先能跑 → 再懂一次 ReAct → 最后碰扩展点
默认你熟悉 Python 异步编程 不知道为什么每个方法都是 async，也不知道流式为什么要 async for 把 asyncio 与事件流当主线讲，而不是当背景知识
示例是片段，不承诺可运行 复制下来缺 import、缺依赖、缺 key，报错信息也对不上 每章给完整文件结构与可运行脚本，代码块标注文件路径
版本更新快，博客滞后 搜到的例子是 1.x 写法，2.0 已经重写或改名 每页对应 2.0.11，附录 D 集中列 1.x → 2.0 的迁移表
本站不做什么

不重复 API 参考、不逐条翻译配置项、不解释 A2A / MCP 协议规范本身。这些官方文档做得比一本教程更好，而且更新更及时。 本站只补四件事：顺序、可运行、选型、踩坑。

三条学习主线：同一章读三遍

每一章都切成三种可读法。不必一次全读，但别只读第一种——只照抄不改，一周后还是不会。

① 跟做线

  • 「读完你能做到」+「最小可跑」+「逐行解读」
  • 目标：10 分钟内看到程序真的输出东西

② 理解线

  • 「端到端」+「速查表」
  • 目标：知道一条用户消息在哪个环节变成模型输入，又在哪个环节变成工具调用

③ 避坑线

  • 「陷阱与窍门」+「自检三问」+「动手练习」
  • 目标：出错时能自己定位到具体模块、配置或代码行

实际建议：第一遍只走 ①，把代码跑起来；第二天通勤路上读 ②；等你真的撞到错误，再回来读 ③。 这时候的阅读吸收率最高，因为你带着问题来。

为什么把「环境与依赖」单独一整章

AgentScope 最容易失败的地方不是 API 用错，而是Python 版本与可选依赖没对上： 核心包要求 Python 3.11+，而服务、RAG、向量库、沙箱各自是独立的 extra。 这一章把「装错」的每一种表现都列出来，比后面任何一章都省时间。

前置知识自查：这些不会会卡在哪

不需要精通，但下面每一条都会在具体章节里用到。括号里是「不会时会卡住的第一处」。

  • Python 3.11+ 基础：类型标注、dataclass / Pydantic 模型、 match 语句（卡在 01 章：看不懂 Agent 的参数与返回结构）
  • asyncio：async def、await、asyncio.run、 async for（卡在 01 章：不知道为什么脚本必须包一层 async def main()）
  • 虚拟环境与包管理：uv 或 pip、pyproject.toml、 extra（卡在 01 章：不知道该装 agentscope 还是 agentscope[full]）
  • HTTP 与 JSON：请求头、状态码、流式响应（卡在 01 章：不知道 401 和 404 分别是谁返回的）
  • 环境变量：os.getenv / os.environ、不把 key 写进代码 （卡在 01 章：模型客户端初始化时直接报错）
如果你完全没写过异步 Python

先花 30 分钟读一遍 Python 官方文档的 协程与任务， 只需要理解 async def、await 和「事件循环负责调度」这三件事。 本站不会重复讲语法，但会在 01 章把「为什么必须 await」讲透。

没有 API Key，能学到哪一步

DeepSeek 需要一个有效的 key，但本站大部分内容是「读 + 跑通结构 + 用假模型」，不调用真实模型也能完成。按章节看：

阶段 没有 Key 能做什么 需要 Key 才能看到的现象
00–01 章 建虚拟环境、装包、写配置、导入模块、用假模型跑通 ReAct 结构 第一次真实请求的回答质量、流式首字延迟、token 用量
02–08 章 读懂 Agent、消息、工具、中间件、权限的代码结构与调用链 工具是否被正确调用、上下文压缩是否触发、权限拦截是否生效
09 章之后 多智能体、RAG、服务、渠道的工程结构与配置 检索质量、团队协作效果、SSE 实际事件顺序
想完全零成本跑通

可以换成本地 Ollama（agentscope[model-ollama] + OllamaChatModel）。 本站默认用 DeepSeek，是因为它便宜、国内直连、并且兼容 OpenAI 协议；换成 Ollama 只需要改两行， 01 章会给出对照。

事实来源：我怎么保证不编

本站只认 AgentScope Python 2.0.11 这一份源码（tag v2.0.11）。 每个「默认值是 50」「base URL 是 https://api.deepseek.com」「这里会抛 RuntimeError」都带 file:line，并在发布前用脚本核对：

  • node tools/check-sources.cjs：每条出处的文件是否存在、行号是否越界、大小写是否与磁盘一致
  • node tools/check-site.cjs：站内链接、锚点、导航与实际小节标题是否一致

如果官方文档与源码冲突，以源码为准，并在正文里同时给出两边出处——这类差异会集中在附录 D。
